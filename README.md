## • InventoryManager SQLite Android

> Aplicación móvil nativa desarrollada en Java y Android Studio para el control de stock local. Implementa operaciones CRUD completas, persistencia de datos con SQLite, validación de formularios, filtros de ordenamiento y un sistema automatizado de alertas para productos con existencias críticas.

---

## • Características principales
- **Operaciones CRUD:** Gestión completa para agregar, consultar, actualizar y eliminar productos del inventario.
- **Persistencia Local:** Almacenamiento estructurado y eficiente utilizando bases de datos SQLite nativas en Android.
- **Validación de Formularios:** Control de entradas para asegurar la integridad de los datos ingresados por el usuario.
- **Filtros y Alertas:** Sistema automatizado de alertas visuales para productos con stock crítico y opciones de ordenamiento[cite: 8].
